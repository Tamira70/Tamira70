### 🚀 Automatisierung Tool

Fullstack-Webanwendung zur digitalen Aufgaben- und Prozessverwaltung mit Django REST API, React, TypeScript und JWT-Authentifizierung.

**Features:**

- Benutzerregistrierung
- JWT Login & Token Refresh
- Demo-Zugang / Gastmodus
- Aufgaben erstellen, bearbeiten und löschen
- Kanban-Board mit Drag & Drop
- Listenansicht, Suche, Filter und Sortierung
- Dashboard mit Statistiken
- Diagramme mit Recharts
- Deployment mit Apache, Gunicorn & HTTPS

👉 [🌐 Live Demo](https://bewerbungsprofil.tamira12.duckdns.org/automatisierung-tool/)  
👉 [💻 GitHub](https://github.com/Tamira70/automatisierung-tool)
